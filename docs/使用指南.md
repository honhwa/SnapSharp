# NimCap Screenshot 使用指南：截图、长截图、OCR、翻译、抠图与录屏

**简体中文** | [English](UserGuide.en.md)

项目地址：[GitHub 主仓库](https://github.com/nimcap/nimcap-screenshot) | [Gitee 镜像（旧仓库名）](https://gitee.com/lilongjiang/SnapSharp)

NimCap Screenshot 原名 SnapSharp，Gitee 镜像保留旧仓库名。问题与功能建议统一提交到主仓库的 [GitHub Issues](https://github.com/nimcap/nimcap-screenshot/issues)；检索历史问题时可同时搜索两个名称，并核对版本。

NimCap Screenshot 是一款 Windows 截图与图像处理工具。除了截图、画箭头和打马赛克，还能把图片置顶贴在桌面上、拼接长截图、识别图片文字、翻译、抠出透明背景，以及录制 MP4 或 GIF。

软件启动后驻留在任务栏托盘，不会默认打开主窗口。日常使用可以从快捷键开始，也可以右键点击托盘图标选择功能。

## 先用一分钟完成第一张截图

1. 启动 `NimCap.Screenshot.exe`，在任务栏右下角找到托盘图标；看不到时展开隐藏图标。
2. 按 `Ctrl+Shift+A`，拖动鼠标框选需要的区域。
3. 在选区旁的工具栏选择箭头、文字或马赛克，直接在截图上标注。
4. 双击选区或点击复制，将结果粘贴到聊天窗口或编辑器；也可以点击保存，或选择置顶贴图。
5. 不需要这次截图时，按 `Esc` 取消。

截图、标注和保存不需要先下载 AI 模型。OCR、抠图和本地翻译需要在首次使用前配置对应模型，下载一次后即可在本机处理。

## 1. 启动、退出与快捷键

### 运行环境

NimCap Screenshot 运行于 Windows 10 2004 及以上版本或 Windows 11，目前提供 x64 程序。

- 使用自包含发布版时，不需要另装 .NET Desktop Runtime；请保留整个程序目录，不要只拷贝 EXE。
- 使用依赖框架的版本时，需要安装 .NET 10 Desktop Runtime。
- 录屏等原生功能可能需要 VC++ x64 运行库及 Windows 媒体组件。
- 模型首次下载需要联网；本地截图、OCR、抠图和本地翻译不需要把内容上传。

双击程序后没有弹出窗口是正常现象。右键托盘图标，可以找到截图、长截图、录屏、贴图、截图历史和设置。

托盘菜单、窗口菜单和贴图右键菜单均带有对应的功能图标。箭头表示还有子菜单，勾号表示当前启用或选中的状态；灰色项目暂时不可用。

### 默认快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+A` | 区域截图 |
| `Ctrl+Shift+F` | 全屏截图 |
| `Ctrl+Shift+W` | 当前窗口截图 |
| `Ctrl+Shift+V` | 从剪贴板创建贴图 |
| `Ctrl+Shift+H` | 隐藏／显示全部贴图 |

在“设置 → 快捷键”中可以修改。注册冲突时会提示，换一个未被其他软件占用的组合后重新保存即可。恢复最近关闭贴图、恢复鼠标交互等可选快捷键可以留空。

托盘中的各项功能均可配置快捷键，并通过每行的“托盘显示”复选框决定是否显示在菜单中。隐藏不影响快捷键；子菜单没有可见功能时自动收起。“设置”和“退出”始终显示，不参与快捷键配置。

托盘还提供 3、5、10 秒延时截图，适合截取菜单、提示框等需要先展开的界面；等待期间可以取消。

要关闭软件，请右键托盘图标选择“退出”。录屏时应先停止并等待文件保存，不要直接结束进程。需要开机启动时，可在设置中开启 Windows 登录时启动。

## 2. 截图后直接标注

区域截图支持矩形、椭圆、自由套索和多边形选区。选择区域后，可以直接在截图上编辑，不必先打开另一个编辑窗口。

工具栏分为两层：主工具栏负责选择工具和输出动作，参数工具栏负责颜色、粗细、线型、填充、字体等选项。部分工具放在分组下拉菜单里，主按钮会复用该组最近使用的工具。

常用工具包括矩形、椭圆、箭头、画笔、荧光笔、文字、气泡、序号、水印、马赛克、模糊、聚光灯和放大镜。已有标注可以选择、移动、缩放、旋转及调整层级，也支持撤销和重做。

选区不合适时，右键会放弃当前选区和标注，让你在同一张桌面快照上重新框选；按 `Esc` 则取消整个截图。

保存或复制时输出的是最终合成图像，不是工具栏和预览界面的截屏。标注模板仅保存对象和样式，不包含截图底图。

### 自动选中按钮、输入框等元素

按 `Ctrl+Shift+A` 开始截图后，默认进入“元素”模式。鼠标悬停在按钮、输入框、链接或其他可识别控件上，会自动吸附并高亮其边界，同时显示控件类型、名称和尺寸。需要其他模式时，可按 `Tab` 或使用顶部捕获模式选择器切换。

- 单击锁定当前元素，随后可以标注、复制、保存或置顶贴图；输出仅包含所选边界内的画面。
- 滚轮向下扩大到父级容器、窗口内容和整个窗口，向上缩小到子元素。
- 也可以直接拖动框选区域。`Tab` 依次切换“区域 → 元素 → 窗口 → 全屏”。
- 识别失败或响应较慢时，仍可选择窗口或手动框选。选区后右键可重新选择，`Esc` 取消截图。

浏览器不需要安装扩展。浏览器通过系统辅助功能接口暴露的网页按钮、链接、输入框等也可以悬停选择；具体覆盖范围取决于浏览器和页面。此模式不支持输入 CSS 选择器、读取完整 DOM 或导出视口外的完整元素。自绘控件、Canvas 和未暴露辅助功能的内容可能只能选到外层容器。

截图使用开始截图时的桌面快照，保留元素内部的实际背景和遮挡内容。元素和窗口模式会按系统圆角或窗口提供的原生区域，将窗口轮廓外的像素设为透明，避免带入对话框圆角外的桌面；PNG 可保留这些透明区域。普通矩形控件保持原形，手动区域截图不套用窗口轮廓。完全自绘且不提供原生区域的透明窗口，以及窗口内部的半透明效果，不会自动还原透明度。跨显示器元素仅截取当前显示器内的部分；目标窗口移动后，需重新开始截图以更新底图和边界。

### 顺手取一个屏幕颜色

在尚未开始选区时，鼠标旁的放大镜会显示像素网格、屏幕坐标和颜色值。

- 按 `Shift`，依次切换 HEX、RGB、RGBA、HSL、HSV/HSB、CMYK 和颜色名称。
- 按 `C`，复制当前格式的颜色值，并退出截图，不生成图片。
- 每次新截图默认使用 HEX。拖动选区时，`Shift` 用于锁定比例，不切换颜色格式。

屏幕快照无法还原窗口原本的透明度，所以 RGBA 的 alpha 为 1。颜色名称可能是最接近的近似名称；CMYK 是 RGB 换算值，不代表经过印刷色彩配置的结果。

### 一键脱敏

截图选区确定后，上方显示“文字识别 O”“总结 J”“一键脱敏 D”，直接按对应字母即可使用，输入文字时不会触发这些快捷键。

按 `O` 后，程序在当前截图原位识别文字，成功后自动将全部文字复制到剪贴板，上方提示复制结果。截图保持原位，仍可拖选原图中的文字，松开鼠标即复制局部；也可按 `Ctrl+A` 全选、`Ctrl+C` 复制，或点击上方“复制全部”（也可再次按 `O`）。蓝色高亮只表示选中文字，不会写入保存的截图。按 `Esc` 或点击“返回编辑”恢复截图标注；识别未完成时也可退出。优先使用已配置或已缓存的本地 OCR，不可用时尝试 Windows OCR；缺少模型及系统语言包时显示提示。

按 `J` 后，总结直接显示在当前截图旁的卡片中，无需跳转到图片编辑或识别窗口。卡片显示处理进度，可选择文字、复制总结、重试或关闭；按 `Esc` 返回截图编辑。已识别的文字会直接复用；直接总结时不会自动复制原文。总结使用已配置的本地 Qwen 模型，缺少模型或处理失败时可从卡片进入配置，保留截图后重试。

复制的 OCR 文字会清理中文之间多余的空格，保留英文词间空格和换行。Windows OCR 会放大小字号截图、分段识别长图；复制全部会保留已识别的文字，即使个别文字框的位置不可用于拖选。

截图时按 `D` 或点击上方“一键脱敏”，贴图时在编辑工具栏点击“一键脱敏”。程序使用已配置的本地 OCR 与规则查找手机号、身份证号、银行卡号、邮箱、车牌号、姓名字段和地址，只模糊对应文字范围。配置本地 Qwen 翻译模型与运行库后，还可辅助分析无标签姓名与地址，候选必须匹配 OCR 原文。

检测效果受 OCR 模型规模与能力、图片清晰度影响；启用 Qwen 辅助时，还取决于所选语言模型的规模与能力。同系列较大模型通常更擅长处理复杂内容，可按设备资源选择兼容模型。结果写入图片，复制与保存会保留；整次操作可撤销／重做。输出前对照原图检查处理范围，必要时手动补充模糊。

### 独立屏幕尺子

从托盘菜单打开“屏幕尺子”，也可在“设置 → 快捷键”中为“屏幕尺子”设置全局快捷键；默认留空，清空即可禁用，重复快捷键会提示冲突。拖动顶部工具栏空白处移动，拖动上下左右四边的蓝色手柄或任意边缘调整范围；右下角也可同时调整宽高。方向键逐个物理像素移动整个尺子。刻度带内侧的蓝色交点为基础坐标 `(0, 0)`，测量坐标不包含刻度带。使用框尺时，框上边和左边的刻度从框左上角零点起算，宽高标签显示在框旁，放大镜显示框内相对坐标；悬停工具栏标题可查看坐标和尺寸。

| 工具 | 操作与用途 |
| --- | --- |
| 直尺 `1` | 拖动或点击两点测长度；可以倾斜，按住 `Shift` 锁定水平或垂直 |
| 框尺 `2` | 拖框实时显示 `W × H`，用于测量按钮、卡片和图片 |
| 两点 `3` | 显示两点坐标、`Δx`、`Δy` 和斜距 |
| 参考线 `G` | 首次点击按钮或按 `G` 生成居中的一横一竖两条参考线，再次操作隐藏或恢复；也可从上方/左侧刻度拖出更多线，拖动调整，右键删除 |
| 角度尺 `A` | 在工具栏中选择，依次点击顶点和两条边上的点；默认关闭 |

各测量工具和快捷键直接显示在顶部工具栏，窄窗口自动换行。每种工具保留一组结果，可同时叠加；点击工具切换当前测量模式，再次点击仍保持选中。按钮右侧的小眼睛控制结果显示。测量数值显示在对象旁，底部保留一行操作提示，悬停可查看完整说明。角度尺按步骤引导取点。按住 `Alt` 吸附附近屏幕边缘、参考线或测量区域边界；按住 `Ctrl` 可在参考线上取点，避免拖动参考线。参考线悬停高亮并显示坐标，光标提示可拖动方向。放大镜默认开启，显示像素和 HEX 颜色，按 `M` 开关；位置自动避开鼠标和测量端点，屏幕采样不可用时会显示提示。

放大镜使用黑白双描边十字准星和像素定位框，纯白或纯黑背景也可定位。准星指向实际采样像素，靠近屏幕边缘时随采样位置偏移；中心留空，保留像素原色。

测量读数优先放在测量范围外，自动避开测量线、角度弧线、端点、其他读数和放大镜；靠近窗口边缘时自动换侧，空间拥挤时寻找可用空白区域。

工具栏的“自动复制”默认关闭，并记住开关状态。开启后，只在测量完成时复制：直尺复制长度，框尺复制 `宽 × 高 px`，两点复制 `Δx`、`Δy` 和斜距，角度尺复制角度。`Ctrl+C` 可手动复制当前工具已完成的结果。拖动过程、取消、参考线移动和窗口缩放不触发复制。底部短暂显示“已复制”，剪贴板被占用时提示按 `Ctrl+C` 重试。

`Delete` 删除选中的参考线或当前工具结果；右键或 `Esc` 取消尚未完成的测量，未开始测量时 `Esc` 关闭尺子。垃圾桶按钮清空全部结果和参考线。独立工具不改变全屏截图尺子的交互。

## 3. 复制、保存与图片格式

截图、贴图、历史和编辑器共用保存窗口。保存前可调整像素尺寸、保持比例，并查看实际编码结果。

| 格式 | 怎么选 |
|---|---|
| PNG | 文字截图、界面截图、透明抠图，优先选择 |
| JPEG | 照片或不需要透明背景的图片；有损压缩，透明部分填白 |
| WebP | 希望缩小体积时使用；支持有损和无损两种模式 |
| TIFF | 无损输出，写入 300 DPI 信息，但不会因此增加像素细节 |
| BMP | 通常文件较大，透明部分填白 |
| PDF | A4 分页输出，长图自动分段；保存窗口左侧仍预览完整图片 |

WebP 的质量 100 不等于无损模式。需要无损时，请明确勾选无损选项。AVIF 当前不提供编码。

保存后可复制文件、复制路径、在资源管理器中定位或打印。替换已有文件需要确认。图片输出每边最多 16384 像素，总计最多 6400 万像素。

### 自动保存和历史记录

自动保存与截图历史是两个独立开关。自动保存默认关闭，可以在设置中指定保存目录、日期归档及文件名模板，例如：

```text
NimCap Screenshot-{date}-{time}-{seq}
```

模板支持 `{date}`、`{time}`、`{width}`、`{height}` 和 `{seq}`。自动命名冲突时会追加后缀；日期归档用于自动保存，不影响手动另存为。

## 4. 把图片或文字贴在桌面上

贴图可以让图片、文字或颜色置顶显示，适合一边看参考资料、一边操作其他窗口。

复制图片、文本或颜色值后按 `Ctrl+Shift+V`，或点击托盘中的“贴图”，即可自动创建对应贴图。颜色值支持 `#RGB`、`#RRGGBB`、`#AARRGGBB`、`rgb(...)`、`rgba(...)` 和 `0xRRGGBB`，直接生成颜色贴图；也可以在截图工具栏选择置顶。

| 操作 | 效果 |
|---|---|
| 滚轮 | 缩放贴图，范围 10%–1000% |
| `Ctrl+滚轮` | 调整窗口透明度，范围 20%–100% |
| 右键 | 编辑、复制、保存、旋转、鼠标穿透、分组、识别及抠图 |
| `Ctrl+Shift+H` | 隐藏／显示全部贴图 |

缩放和窗口透明度不改变保存图片的实际像素；旋转会体现在复制和保存的结果中。

文本贴图的字体、宽度、前景色和背景色可以在“设置 → 贴图”中调整。颜色贴图可以复制 HEX 或 RGB 色值。贴图分组只在本次会话有效，移动组内贴图会带动整组。

开启鼠标穿透后，鼠标会直接操作后面的窗口。如果贴图突然“点不到”，可在“设置 → 快捷键”中为“关闭贴图鼠标穿透”配置快捷键，或勾选在托盘显示该功能。误关贴图时，也可为“恢复最近关闭的贴图”设置快捷键或显示菜单入口。托盘默认只保留一个“贴图”入口。

## 5. 截取网页、列表和聊天记录长图

### 最常用的手动长截图

1. 右键托盘，选择“长截图 → 选择区域并开始长截图…”。也可以在普通截图选区工具栏点击“滚动长截图”。
2. 框选需要采集的内容，调整边缘，点击“开始长截图”或按 Enter 确认。
3. 将鼠标放到区域内，缓慢向下滚动。长截图仅支持竖向滚动。
4. 采集中会持续显示蓝色区域边框、四角及四边中点的八个圆形锚点，便于确认正在滚动哪个区域；边框鼠标穿透，不遮挡区域内的点击和滚轮。保持窗口和选区位置不变，可以向上滚回检查已采集内容。
5. 完成后点击区域右上方的 `√`，进入预览；点击 `×` 或按 `Esc` 则丢弃本次采集。
6. 在预览中检查接缝，按需裁边，然后复制、保存、贴图或继续标注。

手动模式只监听你的滚动，不会替你发送滚轮操作。页面到底或暂时不滚动时，不会自动结束，请手动点击 `√`；托盘“停止当前采集并预览”也能结束。

滚动期间的锚点用于标示固定区域，不支持拖动调整。需要更改区域时，请停止后重新框选，避免采集中改变坐标导致错位。自动采集同样显示区域边框；完成、取消或失败后边框会移除，不进入最终长截图。

滚动过快或动态内容导致无法可靠匹配时，采集会结束并保留当前原始帧，预览自动展开待检查接缝。该帧尚未延长输出图片；请查看两张原始帧，输入正确的非零位移，或排除固定栏后重新匹配，再检查输出。没有重叠内容时应减慢滚动重新采集，手动接缝不能补回未截取的内容。

### 裁边、修正和重新采集

预览中选择上、下、左或右边，再在图片上点击或拖动确定删除范围。裁剪只能从边缘开始，不能从图片中间挖除；可以多次裁边，也能还原完整截图。

展开接缝修正后，可以查看原始帧、微调位移，或排除每帧的固定栏后重新匹配。裁剪和接缝调整支持最多 20 步撤销／重做。诊断线和红色提示不会进入输出图片。

右侧“重新采集（手动／自动）”可以重新框选。自动模式会发送滚轮操作，手动模式只监听实际操作；取消重新采集会保留当前预览。

需要以后继续编辑，可以保存为 `.ssscroll` 拼接工程。工程包含原始截图帧和调整参数，不只是最终长图；分享前注意截图中的隐私内容。

长截图单帧最多 1600 万像素，原始帧合计最多 4800 万像素。输出每边最多 16384 像素、总计最多 6400 万像素，超长内容建议分段采集。采集中不要移动目标窗口或改变屏幕缩放。

## 6. 图像工具：识别、抠图与翻译

在截图工具栏或贴图右键菜单中打开“图像工具”。

<p align="center">
  <img src="../Screenshot/2.png" alt="NimCap Screenshot OCR、条码、表格、公式和抠图模式" width="900">
</p>
<p align="center"><em>同一个窗口可以切换文字识别、证件、二维码与条码、表格、公式、抠图和去水印。</em></p>

1. 在浏览器、聊天软件或其他程序中复制图片内容。注意不是仅复制图片链接或文件路径。
2. 从托盘选择“贴图”，也可以按默认快捷键 `Ctrl+Shift+V`。
3. 右键点击贴图，选择“图像工具”。在左侧选择要使用的模式。
4. 选择模型（如需要），然后点击“开始”“抠图”或“去水印”。

也可以先截图，再点击选区工具栏的扫描文字或剪刀图标。贴图右键、编辑器和长截图结果窗口同样提供识别、抠图入口。

翻译处理的是文字，不是直接把人像或普通图片变成译文。图片中的文字应先经过 OCR，再进行翻译。

### 去水印与图像修复

识别窗口顶部可快速选择模型和处理设备。文字 OCR／证件支持 PP-OCRv6 Tiny、Small、Medium、Windows OCR 和 Tesseract；表格／公式可使用当前配置的本地模型或对应插件；抠图按设备列出兼容模型。选择未安装模型会展示名称、用途和大小，选择官方源或中国源并确认后自动下载、配置路径和设为默认模型；已安装模型可直接切换。Windows OCR、Tesseract 使用 CPU，插件设备由插件管理。

去水印和抠图均在左侧保留原图、右侧显示处理结果，两侧缩放和平移联动，并提供撤销处理结果。图片操作及输出位于预览下方；文字类页面的图片和结果之间可拖动分隔条调整宽度。顶部模型、处理设备和运行按钮合并为一行，齿轮进入设置；二维码页面不显示模型选择。

在识别窗口左侧选择“去水印”，可选择 MI-GAN（快速）、LaMa（默认）或 Moebius（精细候选）。缺模型时留在当前页，按提示选择官方源或中国源并确认；软件自动下载、校验、配置路径和保存默认模型。区域及智能模式缺少 SLBR 时同样自动安装，无需手动转换或寻找文件。涂抹时指针显示笔刷范围；选定区域以蚂蚁线显示。模式、必要参数和“去水印”位于图片下方同一行，框选和智能模式不显示笔刷或阈值，一次点击即完成识别和去除。左侧始终保留原图，右侧检查结果，缩放与拖动同步，并可撤销、复制、保存或贴图。详见[操作、模型与限制](去水印与图像修复.md)。

### 第一次配置 OCR

识别效果与模型大小及能力有关。同系列、同任务且训练与量化条件相近时，较大参数模型通常有助于提高识别准确率，轻量模型则更节省资源、响应更快。实际效果还受训练数据、语言覆盖和图片清晰度影响，应在软件支持的兼容模型中按任务与设备资源选择，不能仅比较下载文件大小。OCR、表格、公式与本地翻译使用各自的模型，升级翻译模型不会改变 OCR 识别结果。

1. 从托盘打开“设置 → OCR 与识别”。
2. 保持默认 PaddleOCR 引擎，初次建议先选 CPU。
3. 找到“PaddleOCR 模型与字典”，选择“PP-OCRv4 · 中文＋英文”。
4. 点击“一键配置推荐 ONNX OCR（下载模型）”，等待约 14.2 MB 模型包下载及校验完成。
5. 确认模型和字典路径已自动填入，点击“保存设置”。

</p>
<p align="center"><em>OCR 引擎、ONNX 计算设备和资源限制都在“OCR 与识别”页面配置。</em></p>

不需要安装 Python 或 CUDA。也可以主动切换到使用系统语言包的 Windows OCR，或选择 Tesseract 并一键下载字库；这三种引擎都在本机处理。

### 识别、校对和翻译

打开文字图片，选择“文字识别”后开始。在“文字／条码”页检查结果，可以修改文字、复制或导出。点击原图识别框和识别行，可以相互定位。

确认文字后点击“翻译…”。可以翻译全文，也可以先选中一段文字。右侧结果为空时，先检查原图是否真的包含文字；人像照片没有文字，OCR 没有结果并不等于图片没有读取成功。

首次翻译可在“设置 → 翻译、API 与隐私”中选择引擎：

- 本地翻译：下载 Qwen3.5 GGUF 模型和配套 llama.cpp 运行库，支持 CPU 或 Vulkan GPU。默认 4B Q4_K_M 模型约 2.81 GiB，运行库另计；还可选择 2B、9B、27B，27B Q5_K_M 仅在至少 24 GiB 专用显存时显示。下载完成后保存设置，文字留在本机处理。
- 在线翻译：可选 MyMemory、Google 网页适配或 LibreTranslate。需要主动启用在线授权，并在发送前确认接收地址和文字；额度、费用和可用性以服务提供方为准。

本地翻译使用的 Qwen 模型提供不同参数规模，同系列较大模型通常能更好地处理复杂语义，代价是更高的内存、显存占用和处理时间。可按设备资源与实际文本选择模型，译文也会受 OCR 原文质量影响；重要内容请先校对原文，再核对译文。单次最多 6000 字符，首次加载可能较慢；失败不会自动切换翻译服务或计算设备。

### 证件字段提取

选择“证件”模式，使用已配置的本地 OCR 判断身份证、驾驶证、行驶证、户口本、护照、银行卡或营业执照，也可通过“更改类型”重新提取。无需另下载证件模型。

身份证支持人像面、国徽面及正反面合图。结果按“字段：内容”显示，可编辑、整段复制或导出 TXT；点击字段行定位原图。缺失字段留空，类型不明确时保留 OCR 原文。输入图片可左／右转 90°、旋转 180°或上下翻转，变换后需重新识别。

字段提取效果取决于所选 OCR 模型的规模、语言覆盖和图片清晰度，可选择兼容模型后重新识别，并逐项核对证件号码、姓名、日期与地址。此功能提取当前页可识别内容，不鉴定真伪，不进行户口本跨页汇总或完整护照 MRZ 解析。

### 条码、表格、公式和屏幕取词

- 条码：选择“二维码／一维码”模式后开始，不需要下载模型。
- 表格：在“设置 → OCR 与识别 → 本地表格与公式”一键配置表格识别并保存，然后框选单张表格，选择“表格识别（本地）”。核对行列和合并单元格后，可修正并导出 CSV 或 XLSX。
- 公式：在同一区域一键配置公式识别并保存，框选单个公式，选择“公式（本地 LaTeX）”。结果可编辑、复制或导出 `.tex`。识别效果受公式模型规模、训练覆盖和图片清晰度影响，可选用兼容的更强模型，并在导出前对照原图核对复杂符号和上下标。
- 屏幕取词：从托盘或已配置的快捷键开启“屏幕取词（本次会话）”。关闭菜单后，将鼠标停在文字上约一秒，识别附近文字，移动后隐藏。优先使用已配置或缓存的本地 OCR；缺模型时尝试已安装的 Windows OCR 语言包，无可用引擎或超时时明确提示。退出软件后不保留开启状态。

## 7. 一键抠图：从图片中分离主体

### 下载模型并设置默认项

1. 打开“设置 → 一键抠图”。
2. 在“选择要下载／配置的模型”中选择一个模型。
3. 点击“一键下载并配置抠图”，等待下载、校验和参数回填完成。
4. 在“默认模型”中选择日常使用的模型，点击“保存设置”。

每个模型分别保存路径、输入尺寸和预处理参数。下载一个新模型不会自动替换默认模型；也不需要一次下载全部模型。

| 原图 | 抠图结果 |
|---|---|
| <img src="../Screenshot/3.png" alt="抠图前的原始人像" width="360"> | <img src="../Screenshot/4.png" alt="NimCap Screenshot 一键抠图结果" width="620"> |

| 模型 | 适合用途 | 约下载大小 |
|---|---|---|
| U²-Net 轻量 `u2netp` | 快速尝试、CPU 轻量处理 | 4.4 MB |
| BiRefNet General Lite | 日常通用抠图，新配置的默认选择 | 224 MB |
| BiRefNet Portrait | 人像精修 | 973 MB |
| BiRefNet Matting | 发丝、软边缘、半透明精修，社区 ONNX 导出 | 941 MB |
| BiRefNet General 完整版 | 高质量通用备选，负担比 Lite 更大 | 973 MB |
| BiRefNet HR Matting | 2048 级输入的大图精修，社区 ONNX 导出 | 932 MB |

建议先安装 General Lite，资源有限时先用 U²-Net。需要人像或发丝精修时再添加对应模型。HR 不是必须项，也不保证每张图片都比普通模型好；模型文件大小不等于运行时显存占用。

### 对复制的图片抠图

1. 复制图片，在托盘选择“贴图”。
2. 右键点击贴图并选择“抠图”。
3. 选择已经配置的模型，点击“抠图”。
4. 对比左侧原图和右侧结果，棋盘格表示透明背景。
5. 需要换模型时重新选择后运行，这不会改变设置里的默认项。
6. 满意后复制图片、保存或置顶贴图。保存透明背景请选择 PNG，或支持透明度的 WebP，不要选 JPEG。

抠图保持原图分辨率，并将结果蒙版与原有透明度相乘。发丝、玻璃和薄纱需要人工检查，玻璃中的背景颜色残留并不一定能靠透明蒙版完全消除。当前不提供拖动框选期间的持续实时抠图预览。

### GPU、超时和失败恢复

“设置 → 一键抠图”提供独立的 CPU／DirectML 选择。CPU 预设为 U²-Net 与 General Lite；Portrait、Matting、General 完整版和 HR 在 DirectML 下提供。多显卡编号沿用 OCR 页的 GPU 编号。旧配置没有独立抠图设备时沿用 ONNX 设备。

超时仍在“设置 → OCR 与识别 → 语言与资源限制 → 推理超时”，范围 1–120 秒，默认 30 秒。等待任务、模型加载、预处理与推理都可能占用时间。大模型可提高超时，但不能用它解决内存不足；固定 2048 输入也不会因手填 1024 自动缩小。

ONNX 推理每次在独立子进程运行，操作结束即释放会话。DirectML 初始化／推理失败、显存预算不足或 GPU worker 异常退出时，程序可在剩余超时内改用 CPU；出错适配器在本次启动期间后续使用 CPU，不修改保存的偏好。取消或超时会终止本次 worker。

- 停止或超时：检查限制，尝试 General Lite 或 U²-Net。
- `8007000E`／`E_OUTOFMEMORY`：减小模型负担；CPU 回退同样需要系统内存。
- 原生 GPU 故障：本次结果可能失败，但 worker 隔离降低其终止主程序的风险；不同驱动和真实大模型仍需实机验证。

DirectML 不需要 CUDA。本地翻译的 Vulkan 是另一条路径，失败不会自动切换 CPU。

## 8. 录制 MP4 或 GIF

### 第一次使用前

进入“设置 → 录屏”，检查录屏环境，并按提示安装缺失组件。VC++ x64 运行库安装可能需要系统确认；Windows N/KN 等缺少媒体组件的系统，需要另外补齐相应组件。麦克风、摄像头还需要 Windows 隐私权限。

### 开始一段区域录屏

1. 按 `Ctrl+Shift+A`，框选单个显示器内的矩形区域，点击录像图标；也可从托盘“录屏 → 录制当前显示器／显示工具条…”进入。
2. 在悬浮录屏工具条点击齿轮，设置 MP4 或 GIF、帧率、质量、采集引擎、鼠标和点击高亮等参数。
3. 需要声音或摄像头时，主动开启对应设备并确认设备名称。这些选项默认关闭，GIF 不支持音频。
4. 点击开始，选择一个新的输出文件。默认 3 秒倒计时，可设置为 0–10 秒。
5. 录制中可暂停／继续；暂停时区域边框变为橙色。点击停止后，等待编码和文件收尾完成。
6. 完成后查看输出路径或打开目录，不要在收尾期间强行退出。

开始前关闭配置窗口会保留悬浮工具条。录制中关闭配置窗口不会停止录制；托盘也提供暂停、继续、停止并保存入口。工具条收起后，可从托盘恢复。

### 格式与常用参数

| 项目 | 说明 |
|---|---|
| MP4 | H.264 视频，可选 AAC 音频；目标帧率可选 15／30／60 fps，实际取决于采集和编码性能 |
| GIF | 无音频，最高 15 fps，最长边 160–800；最多 60 秒、100 MB |
| 默认采集引擎 | WGC；兼容问题时可手动尝试 DXGI，不会静默切换 |
| MP4 码率 | 0 按质量自动；500–100000 kbps 请求固定码率，此时质量档位不控制编码目标；简单画面的实际文件码率可能更低 |
| 定时停止 | 0 表示手动停止，最长 86400 秒；暂停不计入录制时长 |

录屏窗口显示“实际／目标 fps”。出现“帧率不足”时，可降低帧率、缩小选区，或尝试其他采集引擎／编码方式。帧率不足时按时间戳保留实际录制时长，不把少量帧强行当成满帧率播放；定时结束后会显示已达到的有效录制时长，并继续完成文件保存。

录屏只支持单屏矩形区域，不会录入截图上的标注或非矩形蒙版。区域至少 16×16，最大 7680×4320，且总像素不超过约 1660 万；MP4 要求偶数宽高，奇数选区可能裁去最右或最下的一像素。

程序会尝试排除自己的录屏边框和控制工具条，但选区内的其他窗口、贴图及通知仍可能被录入。拖动工具条不会移动录制区域。录制中不要更改分辨率、屏幕缩放或拔插显示器，也不要同时进行长截图采集。

建议先录制十几秒样本，确认画面、麦克风和系统声音。混合音频可能产生回声或过响，可使用耳机并检查设备选择。

### 录制失败后的文件

录屏会在输出目录所在磁盘建立独立临时目录。成功后整理为最终文件；失败时保留临时内容，界面提供“失败临时文件”入口，方便排查或尝试恢复。

强制结束进程、断电可能导致 MP4 缺少末尾索引，不能保证可恢复。临时视频和 GIF 帧也可能包含隐私内容，确认不再需要后再处理；不要直接删除来源不明的目录。

## 9. 设置、本地数据和隐私

设置窗口按分类排列，内容较多时可在右侧向下滚动。修改后需要点击底部“保存设置”；下载模型成功不等于配置已经保存。

程序配置与本地数据默认位于：

```text
NimCap.Screenshot.exe 所在目录
```

可在“设置 → 常规 → 本地数据”浏览或输入新目录，也可点击“使用 exe 所在目录”。保存时会提示迁移已下载模型、设置和历史记录；确认后，从托盘退出程序再重新启动，迁移才会执行，模型和历史索引中的路径也会更新。迁移成功后才删除原数据，目标已有应用数据时会拒绝覆盖。若迁移失败，将保留并继续使用原目录。

旧版兼容目录的实际名称是 `%LocalAppData%\SnapSharp`，更名后仍保留这个路径。启动时优先读取 exe 旁的 `data-location.json`，使用其中记录的当前目录，并在启动时执行已确认的待迁移操作。没有该文件时，只有 exe 目录没有应用数据项、且旧目录存在 `settings.json`、`models`、`History` 等应用数据项，才继续使用旧目录；否则使用 exe 所在目录。若 exe 目录与旧目录都有数据，程序不会自动合并。

可通过上述入口将旧目录的数据迁移到 exe 所在目录或其他目录。手动升级时保留数据目录和 `data-location.json`；若把程序解压到另一目录，原 exe 旁或自选目录中的数据不会仅凭更名自动被找到，请先核对当前数据位置。程序目录和所选数据目录都需要可写。

| 目录或文件 | 内容 |
|---|---|
| `settings.json` | 个人配置、快捷键和模型路径 |
| `models` | 主动下载的模型和字库 |
| `History` | 截图历史、缩略图和索引 |
| `Diagnostics` | 当前数据目录下的诊断信息和自检结果 |
| `Plugins` | 外部插件发现目录，默认不启用外部插件 |

更新程序时请保留数据目录和 `data-location.json`，不要直接删除整个程序目录。手动搬到另一台电脑后，本地模型路径可能需要重新选择。删除模型文件前，先确认没有功能仍引用它。

清理旧版重复下载的模型：打开“设置 → 常规 → 本地数据 → 管理已下载模型”。列表显示当前数据目录 `models` 内的文件夹、文件、占用空间及配置引用状态；本地翻译的模型和运行库会分开列出。选中项目可打开所在位置，或确认后移到回收站。已保存配置、尚未保存的模型路径及全部抠图模型引用的项目不可删除，含链接或无法读取的项目也会禁止删除。未被引用不代表文件重复或没有用途，请核对后操作。模型下载期间入口暂不可用；删除立即生效，取消设置不会撤销。列表不扫描外部自选目录，也不会自动清理旧副本。

本地截图、OCR、抠图和本地翻译不上传图片或文字。模型下载需要联网；在线翻译、以图搜图等会向外部服务发送相应内容，需要主动授权并核对发送预览。

截图历史没有加密。历史图片、长截图工程和录屏临时文件都可能含有敏感信息，不应把本地存储当作加密保险箱。外部插件在进程内运行，不是安全沙箱，开启前务必确认来源。

## 10. 常见问题速查

| 现象 | 优先检查 |
|---|---|
| 启动后没窗口 | 到任务栏托盘或隐藏图标中找 NimCap Screenshot，这是正常启动方式 |
| 快捷键没有反应 | 检查其他软件占用，在设置中重新指定并保存 |
| 剪贴板图片入口读不到图 | 确认复制的是图片内容，而不是链接、文本路径或仅复制文件 |
| 图片显示了，但 OCR 结果为空 | 图片可能没有文字；需要抠图时应切换到抠图模式 |
| 提示缺少模型 | 到对应设置页下载并配置，完成后保存；不要只修改文件后缀 |
| 一键抠图里找不到超时 | 在“设置 → OCR 与识别 → 语言与资源限制”中调整 |
| 大模型提示内存不足或闪退 | 停用 HR + DirectML 组合，完全退出后先用轻量模型或 CPU 验证 |
| 抠图保存后变成白底 | 检查是否用了 JPEG、BMP 等不保留透明度的格式，改用 PNG |
| 贴图无法点击 | 在快捷键设置中启用“关闭贴图鼠标穿透”的菜单入口或配置快捷键 |
| 长截图没有自动结束 | 手动模式需要点击 `√`；到达底部不会自动完成 |
| 长截图错位 | 减慢滚动，避开动态内容，排除固定栏或微调接缝 |
| 录屏没有声音 | 确认选了 MP4、主动开启音频设备并授予系统权限 |
| 录屏失败或文件打不开 | 等待收尾，查看失败临时文件；不要强行结束进程 |

日常使用可以从“快捷键截图 → 直接标注 → 复制或保存”开始。需要处理已有图片时，先将图片贴到桌面，再从贴图右键菜单打开“图像工具”。

## CLI 自动化

脚本截图可使用发布包中的独立 `nimcap.exe`：

```powershell
.\nimcap.exe capture --full --output .\screen.png --json
```

支持固定区域、前台或指定窗口、指定显示器、文件覆盖控制、超时、取消及机器可读结果。`windows --json` 和 `monitors --json` 可查看目标；`capture --process notepad --window-title "记录" --output .\notes.png --json` 可按进程和标题筛选唯一窗口，匹配多个时会报错。`doctor --backend auto --json` 可检查桌面、当前目录写入和实际捕获能力。使用物理像素坐标，需要交互式桌面；完整说明见 [CLI 自动化](CLI.md)。

## 检查与自动安装更新

**从 SnapSharp v1.1.3 或更早版本升级时，需要手动下载新版完整包。** 从 [GitHub Releases](https://github.com/nimcap/nimcap-screenshot/releases) 下载 v1.1.4 或更新版本的 Windows x64 压缩包，完整解压并运行 `NimCap.Screenshot.exe`；此后可使用新版在线更新。保留原数据目录和 exe 旁的 `data-location.json`，并按[数据目录规则](#data-directory)核对当前数据位置。更名版本的具体变化见 [v1.1.4 发版说明](releases/v1.1.4.md)。

每次启动时自动从 GitHub Releases 检查一次最新正式版，并提醒是否有新版；使用期间不会定时检测。打开“设置 → 关于 → 在线更新”会复用本次启动的结果，也可点击“检查更新”主动刷新。发现新版后可点击“下载并安装更新”，页面不再嵌入发版说明，仍可打开发布页面。下载期间可以取消，程序会校验 SHA256、完整包结构和目标版本，校验失败不会安装。

下载完成后会询问是否立即重启安装。请先保存未完成的编辑和设置，并结束录屏、长截图和模型下载。确认后，独立更新助手等待当前进程退出，备份将被替换的文件，自动安装到当前程序目录并启动新版。已保存的配置、模型、历史记录和发布包之外的文件会保留。

文件替换失败时，助手会恢复已经替换的旧文件并尝试重启旧版；若回滚也受权限或占用影响，会显示备份路径以便恢复。备份和安装结果位于系统临时目录的 `NimCap.Screenshot-updates/本次更新标识/` 下。该回滚针对安装过程中的失败，不是新版运行后的健康检查。

程序目录需要当前用户拥有写入权限，不会自动请求管理员权限。GitHub 不可用、限流、校验信息缺失或磁盘空间不足时可稍后重试。安装失败前，当前进程不会因下载错误而退出。
