## 当前概况

日常截图、标注、保存、贴图和 CLI 已形成可用闭环。当前维护重心是可靠性与实际使用问题；新功能应有明确场景，避免为了补齐路线图而扩展。

| 能力域 | 当前结论 | 主要边界 |
|---|---|---|
| 截图、选区、编辑与输出 | 主流程已接通 | 混屏／多 GPU 仍需实机覆盖；性能指标另行测量 |
| 独立 CLI | v1.1.7 已发布，满足日常脚本截图 | 需可访问的交互式桌面 |
| 贴图与竖向长截图 | 常用操作、接缝修正和输出已接通 | 动态页面、重复纹理及真实混屏仍需验收；不承诺横向长截图 |
| 本地 AI 与图像处理 | OCR、证件、条码、表格、公式、翻译、抠图、去水印均有入口 | 模型按需配置；样本精度、资源占用和设备兼容分项评估 |
| 录屏 | MP4／GIF、暂停、定时及设备选项已有实现 | 长时音画同步、60fps、设备拔插和硬编回退仍有验收缺口 |
| 历史与用户数据 | 合成图历史、按条数清理和数据迁移已有流程 | 搜索、收藏、历史标注恢复及容量／天数清理尚不完整 |
| 工作流、通用上传与企业能力 | 保留为候选，暂不安排 | 不作为日常功能完整性的前提 |

## 推荐路线图

### 近期：日常维护与已知缺口

| 顺序 | 工作 | 对应编号 | 完成判断 |
|---|---|---|---|
| 1 | 修复可复现的截图、编辑、保存、贴图或 CLI 故障；保持当前命令契约稳定 | T-10、C、S、O、A、P | 问题有复现步骤，修复后相关回归通过，无新增使用步骤 |
| 2 | 检查错误诊断脱敏、用户内容保留和异常临时数据，按实际需要补充清理 | X-02、X-03、H-03 | 可辨认可恢复录屏与普通残留，不误删用户数据，清理范围明确 |
| 3 | 为性能与兼容问题建立可复测证据，再按瓶颈处理 | N-01、N-02、N-04、N-05 | 记录环境、样本、时间／像素误差；不以缓存微基准替代完整交互性能 |

CLI 本轮范围已闭合，暂不增加动作链、编排器或额外输出模式。日常脚本截图统一使用 T-10。

### 持续：已有能力的专项验收

| 范围 | 待补证据 | 对应编号 |
|---|---|---|
| 多屏与捕获 | Windows 10/11、100%＋150% 混屏、竖屏、热插拔及不同 GPU；记录真实像素边界 | C-07、C-08、N-04、N-05 |
| 长截图 | 浏览器／Electron／Office 竖向页面，固定栏、动态内容、重复纹理、手动接缝与区域指示框 | L-01～L-07 |
| 本地 AI 与脱敏 | 真实复杂样本、漏检／误检、文字范围、透明边缘、修复细节和模型资源占用 | R-01、R-07～R-09、R-12～R-15、X-05 |
| 录屏 | 10 分钟音画同步、各目标帧率、音频／摄像头拔插、硬编失败与停止保存 | V-01、V-02、V-04～V-09 |

### 按需：暂不承诺排期

- **编辑细节**：评估将连续拖动属性滑块合并为一次撤销，减少调整参数后的重复撤销操作（A-07、A-17、A-18）。
- **历史体验**：先评估日期／尺寸过滤、收藏及容量／天数清理；历史再次编辑需保存原图和标注数据，不能从合成 PNG 恢复对象（H-02～H-06）。
- **配置与插件**：完整配置导入／导出、可信发布者验证和不可信插件隔离，仅在明确需要时推进（N-08、N-09）。
- **重型扩展**：动作链、可视化编排、上传／Webhook、批量处理、历史加密、企业策略及审计保留为候选（W-01～W-08、X-04、X-06、X-07）。

### 使用与验收边界

- **入口**：托盘“识别粘贴板图片…”先预览，再选择工具，不自动运行；翻译消费 OCR 结果或输入文字。截图自动扫码属于 R-05，敏感文字模糊属于 X-05。
- **抠图模型**：内置六种配套预设，CPU 设置列出 U²-Net 与 General Lite，其他预设在 DirectML 下提供。General Lite 为新配置默认，旧配置保留原选择；不提供拖动选区期间持续实时抠图。大小、设备与契约见[配置与依赖：抠图](配置与依赖.md#cutout)。
- **推理风险**：HR + DirectML 曾出现内存分配失败和原生驱动崩溃；现有进程隔离、显存检查及 CPU 回退降低故障对主进程的影响，但不能替代真实模型／显卡验收。详见[异常与推理隔离](异常与推理隔离.md)。
- **质量评估**：OCR、证件、表格、公式、翻译、抠图和去水印分别按真实样本验收。下载校验或合成模型推理通过，不代表真实图片准确率；图像修复细节见[去水印与图像修复](去水印与图像修复.md)。
