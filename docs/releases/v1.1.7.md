# NimCap 截图工具 v1.1.7

## 中文

本次新增独立命令行工具 **`nimcap.exe`**，方便通过 PowerShell、批处理或自动化脚本完成日常截图，无需先启动托盘程序。

- **截图自动化**：支持整个桌面、固定物理像素区域、指定显示器、前台窗口和指定窗口句柄，提供延时、超时、取消、鼠标指针及捕获后端选项。
- **查找目标**：`windows` 列出窗口句柄、标题、进程和边界；`monitors` 列出显示器编号、分辨率、DPI 和缩放。支持按进程名、标题或两者组合选择窗口；匹配多个窗口时明确报错。
- **脚本输出**：支持 JSON 结果和明确的退出码，输出 PNG、JPEG、WebP、TIFF、BMP 或 PDF。默认保护已有文件，使用 `--overwrite` 才允许替换。
- **环境诊断**：`doctor` 检查桌面访问、目录写入，以及 GDI、WGC 和自动回退后端的实际捕获能力，并逐项报告结果。
- 中英文 README 已补充 CLI 介绍、命令示例及详细文档入口。CLI 使用物理像素坐标，支持负坐标，不修改剪贴板、应用设置或截图历史。

```powershell
.\nimcap.exe capture --full --output .\screen.png --json
.\nimcap.exe windows --json
.\nimcap.exe monitors --json
.\nimcap.exe capture --monitor 1 --output .\primary.png --json
.\nimcap.exe doctor --backend auto --json
```

完整参数、窗口筛选规则、退出码及运行限制见 [CLI 使用说明](https://github.com/nimcap/nimcap-screenshot/blob/v1.1.7/docs/CLI.md)。CLI 需要可访问的交互式 Windows 桌面；锁屏、断开的远程桌面或受保护内容可能限制捕获。自动化任务应在用户已登录的会话中运行。

下载 **`nimcap-screenshot-v1.1.7-win-x64.zip`** 并完整解压。桌面程序运行 `NimCap.Screenshot.exe`，命令行使用 `nimcap.exe`。压缩包包含 .NET 运行时，SHA-256 校验值见 `SHA256SUMS.txt`。已有模型、个人设置和历史记录仍保留在原数据目录；v1.1.4 及之后版本可通过内置更新器升级，SnapSharp v1.1.3 或更早版本需手动下载完整包。

## English

This release adds the standalone **`nimcap.exe` CLI** for everyday screenshot automation with PowerShell, batch files, and scripts. The tray application does not need to be running.

- **Automated capture:** Capture the full desktop, a physical-pixel rectangle, a specific monitor, the foreground window, or a window handle. Options include delay, timeout, cancellation, cursor capture, and backend selection.
- **Target discovery:** `windows` lists handles, titles, processes, and bounds; `monitors` lists display indices, resolutions, DPI, and scale. Select a window by process name, title, or both. Multiple matches fail explicitly.
- **Script-friendly output:** JSON results and defined exit codes, with PNG, JPEG, WebP, TIFF, BMP, and PDF output. Existing files are protected unless `--overwrite` is specified.
- **Environment diagnostics:** `doctor` checks desktop access, directory writes, and real capture with GDI, WGC, and the automatic fallback backend, reporting each result separately.
- Both READMEs now include a CLI overview, examples, and documentation links. CLI coordinates use physical pixels, including negative origins. Capture does not modify the clipboard, application settings, or screenshot history.

```powershell
.\nimcap.exe capture --full --output .\screen.png --json
.\nimcap.exe windows --json
.\nimcap.exe monitors --json
.\nimcap.exe capture --monitor 1 --output .\primary.png --json
.\nimcap.exe doctor --backend auto --json
```

See the [CLI guide and English quick reference](https://github.com/nimcap/nimcap-screenshot/blob/v1.1.7/docs/CLI.md#english-quick-reference) for options, window matching, exit codes, and limitations. An accessible interactive Windows desktop is required; locked sessions, disconnected remote desktops, and protected content may restrict capture. Run scheduled tasks in a logged-in user's session.

Download **`nimcap-screenshot-v1.1.7-win-x64.zip`** and extract the entire archive. Launch `NimCap.Screenshot.exe` for the desktop application or use `nimcap.exe` for command-line capture. The package includes the .NET runtime; verify it against `SHA256SUMS.txt`. Existing models, settings, and history remain in their data folders. Versions 1.1.4 and later can use the in-app updater; SnapSharp 1.1.3 and earlier require a manual download of the complete package.
