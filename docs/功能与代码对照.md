## 执行与数据边界

- 截图、标注、贴图、测量、条码无需 AI 模型。其他识别任务需配置模型或字库；Windows OCR 使用系统语言包。
- PaddleOCR、表格、公式、抠图通过每次操作独立启动的 ONNX worker 运行。GPU 失败或显存预算不足可回退 CPU；出错适配器在本次启动期间后续使用 CPU，保存的设备偏好不变。取消／超时终止 worker，跨请求不保留会话缓存。
- 本地翻译使用 GGUF + llama.cpp，设备为 CPU／Vulkan，与 ONNX 独立；Vulkan 未成功卸载模型层时直接报错。在线翻译和图片搜索需授权开关及逐次确认。
- 历史保存合成 PNG、缩略图与索引；`.sstemplate` 标注模板、`.ssscroll` 长截图项目不能让历史恢复原始标注对象。
- 默认数据在程序目录，可在设置安排下次启动迁移；录屏目录可独立设置。缺模型时不会隐式下载。
- 独立 CLI 不加载桌面配置，不写截图历史、不修改剪贴板，也不主动隐藏已有 GUI 窗口；需要可访问的交互式桌面。

## 尚未提供或仍有限制

- 元素捕获依赖 Win32／UI Automation 的可见几何，不提供 CSS 选择器和视口外完整 DOM 截图。
- 长截图以竖向内容为主；复杂动态页面与重复纹理需检查接缝，横向滚动不作承诺。
- 证件基于 OCR 与规则提取当前页，不提供真伪鉴定、完整护照 MRZ、银行卡 BIN 查询或户口本跨页成员汇总。
- 不提供拖动选区时持续实时抠图；CPU 设置只列 U²-Net、General Lite，其他内置预设在 DirectML 下提供。GPU 回退仍可能受 CPU 内存与超时限制。
- 通用上传、用户编排动作链、历史全文检索／收藏、历史标注对象恢复、不可信插件沙箱未完成。
- `-clip` 已解析但未接通输出决策，不能作为完整无交互复制功能。插件契约存在不代表每类能力都有主界面入口。
